`etos256us.img` is **EmuTOS 1.4** (free TOS, GPL v2, https://emutos.sourceforge.io). It is provided so that Hatari starts without an Atari ROM. With a real TOS 1.62 or 2.06 ROM, pass it with `--tos`.

To see the game on screen instead of in an AVI: `SDL_VIDEODRIVER= run/run.sh out`, or simply run `hatari` on the `out/` folder.
