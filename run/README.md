`etos256us.img` est **EmuTOS 1.4** (TOS libre, GPL v2, https://emutos.sourceforge.io). Il est fourni pour que Hatari démarre sans ROM Atari. Avec une vraie ROM TOS 1.62 ou 2.06, passez-la à `--tos`.

Pour voir le jeu à l'écran plutôt que dans un AVI : `SDL_VIDEODRIVER= run/run.sh out`, ou lancez simplement `hatari` sur le dossier `out/`.
